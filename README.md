# Tableau-DERJU

Projet Android pour un tableau flottant de statistiques de dés, avec interface sombre translucide et accents néon bleu/violet.

## Compilation
Le workflow GitHub Actions compile l'APK debug à chaque push sur `main`, ou manuellement depuis l'onglet Actions. Télécharger l'artefact `Tableau-DERJU-APK`.

## Fonctions incluses
- Saisie manuelle des sommes de dés de 2 à 12.
- Compteurs et comparaison des fréquences observées aux probabilités théoriques de deux dés équilibrés.
- Fenêtre flottante déplaçable par sa barre supérieure.
- Commandes de zoom et modes grand, compact, miniature.
- La détection automatique des dés n'est pas encore implémentée.
